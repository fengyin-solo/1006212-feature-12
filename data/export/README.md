## 缺测分档处理

- 半天（连续中断1个时段）：连续中断1个时段（半天）：按相邻时段线性内插补齐
- 一天（连续中断2~5个时段，1天以上、3天以内）：连续中断2~5个时段（1天以上、3天以内，含2天）：按前后有效读数线性内插补齐
- 三天以上（连续中断6个时段及以上）：连续中断6个时段及以上（连续3天及以上）：不补数值，按缺测处理，保留原始缺测标记

补齐记录保留「原始缺测=是」与「缺测处理」标记，不抹掉缺测痕迹。
